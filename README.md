# Resolvendo Códigos em Python com GitHub Copilot
</div>

---

# Descrição 
---

Neste projeto, a ideia é solucionar alguns problemas
usando o Copilot do GitHub.

Teremos 3 problemas bases para resolver.

---

# 1 - Concatenar Dados 

Descrição do problema: 

Iremos receber 2 dados diferentes do usuário e concatenar em uma única
```string```

---

# 2 - Repetição de textos

Descrição do problema: 

Vamos solicitar uma ```string``` e um número inteiro como entrada.
Depois retonaremos o número de vezes informado.

---

# 3 - Operações matematicas simples 

Descrição do problema: 

Vamos solicitar como entrada 2 números e depois realizar uma 
operação simples entre eles.

---

#  Estrutura dos Desafios

## 1 Concatenar Dados

### Descrição

Receber dois dados informados pelo usuário e concatená-los em uma única `string`.

### Exemplo

**Entrada**

```text
Olá
Mundo
```

**Saída**

```text
Olá Mundo
```

---

##  Repetição de Texto

### Descrição

Receber uma `string` e um número inteiro.

Retornar a string repetida a quantidade de vezes informada.

### Exemplo

**Entrada**

```text
Python
3
```

**Saída**

```text
Python
Python
Python
```

---

## Operações Matemáticas Simples

### Descrição

Receber dois números e realizar uma operação matemática simples entre eles.

Exemplo de operações:

- Soma
- Subtração
- Multiplicação
- Divisão

### Exemplo

**Entrada**

```text
10
5
```

**Saída**

```text
Soma: 15
Subtração: 5
Multiplicação: 50
Divisão: 2.0
```

 Objetivos de Aprendizagem

- Manipulação de Strings
- Entrada e Saída de Dados
- Operadores Matemáticos
- Estruturas Básicas do Python
- Boas práticas de programação
- Utilização do GitHub Copilot como ferramenta de apoio
